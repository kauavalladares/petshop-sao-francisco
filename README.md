# 🐾 Pet Shop

Sistema web desenvolvido para modernizar o atendimento da pet shop, permitindo que os clientes conheçam os serviços oferecidos e realizem agendamentos de banho e tosa de forma simples e prática.

Além da área destinada aos clientes, o sistema conta com um painel de gerenciamento para controle da agenda de atendimentos, facilitando a organização dos horários e dos serviços agendados.

## ✨ Principais Funcionalidades

- Apresentação dos serviços da pet shop;
- Agendamento online de banho e tosa;
- Gerenciamento da agenda de atendimentos;
- Interface intuitiva e responsiva.
